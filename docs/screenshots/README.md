# 실행 증거

| 파일 | 확인 가능한 내용 |
|---|---|
| `power-automate-success.png` | 메일 수신, HTTP 호출, 응답 파싱, 검증 분기, 승인 및 알림의 성공 경로 |
| `tool-calling-log.png` | 상품 검색 후 주문 검증 도구 호출 |
| `run-history-success.png` | 실행 성공 상태 및 승인 대기를 포함한 실행 시간 |
| `approval-request.png` | 상품 및 주문 조건을 포함한 담당자 승인 요청 |
| `approval-result.png` | 담당자 승인 후 Approved 상태 |
| `order-approved-email.png` | 수량 50, 총액 499.5의 주문 승인 완료 알림 |

실제 실행에서 확보한 캡처 6개를 내용 변경 없이 공개용 파일명으로 복사했습니다.

성공 응답은 [JSON 예시](../examples/agent-order-success.json)와 함께 확보한 [원본 응답 텍스트](../examples/agent-order-success.txt)로 제공합니다. 텍스트 파일의 원래 이름은 `200.txt`입니다.
